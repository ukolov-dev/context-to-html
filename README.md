# Context to HTML

`context-to-html` — open-source скилл для Codex, который превращает указанный контент или контекст разговора в красивую, содержательную HTML-визуализацию.

Результат — один автономный `.html`-файл. Весь HTML, CSS, JavaScript и SVG находятся внутри него: не нужны сборка, фреймворк, CDN или внешние шрифты.

## Что умеет

- извлекает смысл из текущего разговора, заметок или указанного файла;
- подбирает визуальную форму под содержание: таймлайн, процесс, сравнение, карту связей, систему, план или редакционный эксплейнер;
- сохраняет факты, числа, оговорки и неопределённость исходного материала;
- создаёт адаптивную страницу для широкого и узкого экрана;
- учитывает доступность, клавиатурную навигацию и `prefers-reduced-motion`;
- проверяет результат в браузере, если браузерные инструменты доступны Codex.

Скилл предназначен для одностраничных визуальных материалов. Для полноценных многофайловых сайтов и веб-приложений лучше использовать специализированный frontend workflow.

## Установка в Codex

Codex загружает пользовательские скиллы из `$HOME/.agents/skills`. Для установки понадобится Git.

### macOS и Linux

```bash
mkdir -p "$HOME/.agents/skills"
git clone https://github.com/ukolov-dev/context-to-html.git \
  "$HOME/.agents/skills/context-to-html"
```

### Windows PowerShell

```powershell
New-Item -ItemType Directory -Force "$HOME/.agents/skills" | Out-Null
git clone https://github.com/ukolov-dev/context-to-html.git `
  "$HOME/.agents/skills/context-to-html"
```

Codex обычно обнаруживает новый скилл автоматически. Если `$context-to-html` не появился в списке, перезапустите Codex.

Проверить наличие скилла в Codex CLI или IDE extension можно командой `/skills` либо начав вводить `$context-to-html` в сообщении.

## Обновление

```bash
git -C "$HOME/.agents/skills/context-to-html" pull --ff-only
```

После обновления Codex также подхватывает изменения автоматически; если этого не произошло, перезапустите его.

## Использование

Самый предсказуемый способ — явно указать скилл в запросе:

```text
$context-to-html преврати обсуждённую выше идею в красивую HTML-визуализацию.
```

Другие примеры:

```text
$context-to-html сделай визуальный конспект этого разговора для руководителя.
```

```text
$context-to-html сравни три предложенных подхода и покажи компромиссы в одном HTML-файле.
```

```text
$context-to-html преврати roadmap.md в интерактивный таймлайн. Сохрани как roadmap.html.
```

```text
$context-to-html покажи связи между участниками, проблемами и решениями из обсуждения выше.
```

Можно не указывать скилл явно: Codex способен выбрать его автоматически, когда запрос соответствует описанию. Явный вызов полезен, если HTML-файл нужен гарантированно.

## Что получится

По умолчанию скилл:

1. Берёт указанный материал или релевантную часть текущего разговора.
2. Определяет главный вывод и подходящую визуальную структуру.
3. Создаёт один автономный HTML-файл в текущей рабочей папке.
4. Проверяет вёрстку на широком и узком экране, если доступны браузерные инструменты.
5. Возвращает кликабельную ссылку на готовый файл.

Путь и имя результата можно задать прямо в запросе:

```text
$context-to-html создай визуальный отчёт и сохрани его в docs/strategy-overview.html.
```

## Структура репозитория

```text
context-to-html/
├── SKILL.md
├── agents/
│   └── openai.yaml
└── references/
    └── visual-standard.md
```

- `SKILL.md` определяет область применения и основной workflow.
- `references/visual-standard.md` содержит стандарт информационного и визуального дизайна.
- `agents/openai.yaml` задаёт название, описание и пример запроса в интерфейсе Codex.

Подробнее о структуре, установке и вызове skills: [официальная документация OpenAI](https://learn.chatgpt.com/docs/build-skills).
